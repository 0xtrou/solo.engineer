## Phase 5 — Per-article categorization (core algorithm)

**New function in `lib/terminal-feed.ts`:**

```ts
const categoryKeywords: Record<TerminalCategory, string[]> = {
  "Power & grid": ["power","electricity","grid","energy","generation","transmission","battery","storage","lng","natural gas","nuclear","solar","wind","substation","transformer","电力","能源","电网","储能","điện","điện lực","lưới điện","năng lượng"],
  "Policy & controls": ["policy","regulation","rule","ban","export control","sanction","tariff","compliance","directive","order","federal register","政策","监管","管制","出口","chính sách","quy định","cấm"],
  "Hardware & compute": ["chip","semiconductor","gpu","cpu","tpu","wafer","fab","foundry","node","transistor","memory","hbm","芯片","半导体","集成电路","算力","bán dẫn","vi mạch"],
  "Capital & costs": ["billion","million","funding","raise","ipo","investment","capex","valuation","venture","vc ","deal","cost","price","投资","融资","đầu tư","vốn"],
  "Technology & research": ["ai ","artificial intelligence","llm","model","training","inference","algorithm","research","r&d","breakthrough","人工智能","模型","研发","trí tuệ nhân tạo","chuyển đổi số","công nghệ"],
};

function categorizeArticle(title: string, summary: string | undefined, fallback: TerminalCategory): TerminalCategory {
  const text = `${title} ${summary ?? ""}`.toLowerCase();
  let best = fallback;
  let bestScore = 0;
  for (const [category, terms] of Object.entries(categoryKeywords)) {
    const score = terms.reduce((acc, term) => acc + (text.includes(term) ? 1 : 0), 0);
    if (score > bestScore) { bestScore = score; best = category as TerminalCategory; }
  }
  return best;  // fallback if no keyword hits
}
```

## Risks & mitigations
- **Nikkei RDF parse**: if regex misses, source shows unavailable — acceptable (try/catch isolates). Will verify in build.
- **Vietnamese keyword matching**: false positives possible — mitigated by `titleOnlyRelevanceSources` + tight term lists.
- **Paywalled articles** (Bloomberg/WSJ): feed titles/summaries free, article links work, user hits paywall at origin — acceptable, same as existing Federal Register pattern.
- **Fetch latency**: 21 sources — concurrency limiter (Phase 7) caps parallelism, 15s timeout per source isolates slow ones.
- **Contracts enum change**: removing `ndrc-releases` — grep confirms no external dependency beyond `lib/terminal-feed.ts` adapters (being removed). `apps/api` canonical backend uses its own source list (separate deploy path, not affected by this Next.js deploy).
