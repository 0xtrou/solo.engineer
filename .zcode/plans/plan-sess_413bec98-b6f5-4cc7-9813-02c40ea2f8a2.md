## Goal
Per-source quality scoring: provenance yield + composite score + category authority profile + citation in-degree. Surface in both sidebars. Four signals, layered.

## Prerequisites (close data gaps first)

**P1 — Home items get categoryScores server-side** (`lib/feed.ts:511`)
Currently `getFeedSnapshot` only stamps `tier`. Add `categoryScores: scoreCategoriesKeyword(...)` via existing helper. Without this, home `sourceAvgScore` is always 0.

Currently `if (maxScore(scores) === 0) return []` discards items before counting. Track raw entry count per source separately, surface on `TerminalSourceStatus` as `rawItemCount`. Enables real yield = scored/rawn.

## Phase 1 — Provenance yield (per-source)

**Home** (`components/feed-dashboard.tsx:sourceAvgScore` memo, lines 338-349):

## Phase 2 — Category authority profile (per-source)

**New helper `lib/source-quality.ts`:**
`categoryAuthority(itemsBySource): Map<sourceId, Record<Category, number>>` — for each source, distribution of its items across the 5 categories (e.g. SCMP: HW 40%, POL 30%, CAP 20%, PWR 10%, R&D 0%). Detects specialization vs generalist.

Computed client-side from items (already categorized). No server change.

## Phase 3 — Citation in-degree (per-source)

**New `lib/source-domains.ts`:**
- `homeSourceDomains: Record<SourceId, string[]>` — authored map (arxiv→["arxiv.org"], hacker-news→["news.ycombinator.com"], github→["github.com"], etc. for 46 sources). One-time authoring.
- `terminalSourceDomains` — derived from `sourceDefinitions` (already has homepage per source).

**Citation scanner `lib/source-quality.ts`:**
`citationInDegree(allItems, domainMap): Map<sourceId, number>` — for each item, scan `title + summary` for mentions of any source's domain. Increment in-degree counter for the cited source. Aggregator-safe (ignores item's own URL host, only scans text).

Public-suffix-aware: extract registrable domain via `URL.hostname` + strip `www.` + handle common suffixes. No new dep — small helper.

## Phase 4 — Composite sourceQuality

**`lib/source-quality.ts:compositeSourceScore({yieldPct, tierRank, freshness, yieldVolRatio, citationInDegree, engagement}): number`**
Weights:
- provenanceYield × 0.40 (honest signal dominant)
- tierRank × 0.25 (editorial baseline, normalized 0-1)
- freshness × 0.15 (items in last 7d / max-items-source)
- yieldToVolumeRatio × 0.10 (curated > spammy)
- citationInDegree × 0.10 (normalized to max)

Returns 0-100. Single number per source.

Engagement dropped (HN/SO bias unfair to primary sources like Federal Register).

## Risks
- **Home categoryScores perf**: `scoreCategoriesKeyword` runs per item at fetch. ~240 items × precompiled regex = fast (<50ms). Acceptable.
- **Citation scan**: O(items × sources × domain-patterns). 240 × 46 × ~2 = ~22k regex tests per render. Memoize. Cache result keyed on feed fingerprint.
- **Domain authoring**: 46 home sources need domain map. Manual but one-time. Some sources share domains (dev.to, hashnode.com blogs) — map to canonical.
- **Aggregator noise**: HN summaries often link to random domains not in our source set → no false citations (only matches known source domains). Safe.
